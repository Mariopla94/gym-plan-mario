GYM PLAN MARIO — COMO SUBIRLO
=============================

OPCION A — VERCEL (recomendado, ya lo usas)
1. Entra a vercel.com y haz login
2. Click "Add New..." -> "Project"
3. Arrastra ESTA CARPETA COMPLETA (o sube el .zip y descomprime)
   - Si prefieres: crea un repo en GitHub con estos archivos y conectalo
4. Framework Preset: "Other"
5. Deploy
6. Te da una URL tipo: gym-plan-mario.vercel.app

OPCION B — NETLIFY DROP (mas rapido, sin cuenta)
1. Entra a netlify.com/drop
2. Arrastra la carpeta completa
3. Te da la URL al instante

DESPUES — AGREGAR A PANTALLA DE INICIO (iPhone)
1. Abre la URL en SAFARI (no Chrome)
2. Boton compartir (cuadro con flecha arriba)
3. "Agregar a pantalla de inicio"
4. Confirma el nombre: Gym Plan Mario
5. Listo — abre en pantalla completa, sin barra de navegador

ARCHIVOS
- index.html    -> la app completa
- manifest.json -> config para que funcione como app nativa
- icon.png      -> icono en la pantalla de inicio
- vercel.json   -> config de Vercel (evita cache vieja)

NOTA IMPORTANTE
Tus datos (comidas, medidas, fotos) se guardan SOLO en tu iPhone.
No se suben a internet. Si borras los datos de Safari, se pierden.
